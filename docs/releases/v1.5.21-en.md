# Hazel · Codex Dream Skin v1.5.21

[中文](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.21/docs/releases/v1.5.21.md) · **English**

The Hazel (灰泽满) theme now sits on top of upstream Codex Dream Skin v1.5.21 and is adapted to Codex 26.1013, where ChatGPT and Codex share one window. This is the fork's first release on the upstream 1.5 line, with installers for macOS and Windows.

## New features

- **Hazel is the default theme**: fresh installs on macOS and Windows start on the Hazel theme; upstream's public preset, Gothic Void Crusade, stays available under saved themes. Installs already using another theme keep it after upgrading.
- **Artwork on the ChatGPT side**: the ChatGPT home, chat and Work pages show a translucent Hazel figure on the right that fades out toward the bottom.
- **Update source**: update checks and download links point to this fork's Releases.

## Fixes and improvements

- **Codex home**: fixed an empty placeholder card that pushed the composer out of the window and suggestion rows whose text disappeared; the hero card shrinks between 300px and 240px when the window is short or a usage banner is shown.
- **Quote**: pinned inside the hero card, left of the figure; pages without the card no longer show a stray quote.
- **Brand**: "灰泽满 Hazel / 绿冻工作台" moved to the title bar above the sidebar and hides while the sidebar is collapsed, so it never overlaps the thread title.
- **Sidebar seam**: removed shadows and outlines left over from the older split-panel layout; the area between the two rounded corners matches the title bar, and the corners line up with the sidebar collapsed.
- **macOS**: switching to another theme and back to Hazel no longer drops the chibi sticker.

## Upgrading and usage

- **macOS**: use the one-line installer in the README, or download the DMG. Upgrading from 1.4.x replaces the old engine and keeps the active theme. The public build is not signed by Apple, so the DMG needs the first-run approval in the [installation guide](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.21/docs/install-macos.md); the one-line installer does not.
- **Windows**: the installer is tested and built automatically on GitHub Actions' Windows runners and has not yet been checked on a physical Windows machine. Known issue: switching to another saved theme from the tray and back to Hazel drops the chibi sticker; the rest of the theme is unaffected, and reinstalling restores it.
- **Artwork**: the character art and sticker belong to their original creators and are not covered by the MIT license; see [NOTICE](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.21/macos/NOTICE.md).
