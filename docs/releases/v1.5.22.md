# 灰泽满 Hazel · Codex Dream Skin v1.5.22

**中文** · [English](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.22/docs/releases/v1.5.22-en.md)

修复侧栏与内容区交界处的两处细线问题，并为 Windows 单独调整布局；macOS 与 Windows 的布局从此各自独立。

## 修复与改进

- **侧栏滚动条（macOS）**：会话列表滚到底时，滚动条不再伸出侧栏右下角的圆角。
- **拖动提示线（macOS）**：鼠标移到侧栏与内容区之间的拖动区域时，提示线只出现在两块面板之间，不再从上下圆角缺口里露出。
- **Windows 布局**：侧栏与内容区改为直角边框；品牌字移到窗口菜单栏中间，窗口较窄时自动隐藏；会话区上下渐隐统一为主题底色；氛围立绘与主卡片立绘的位置和缩放重新对齐。
- **平台分离**：上述 Windows 调整只在 Windows 生效，macOS 布局保持不变。

## 升级与使用

- **macOS**：重新运行 README 中的一键安装命令，或下载新的 DMG，当前主题保留。
- **Windows**：下载新的 Setup.exe 覆盖安装。Windows 安装包由 GitHub Actions 的 Windows 环境测试与打包，尚未在实体 Windows 设备上验收；在托盘里切到其他主题再切回灰泽满时 Q 版贴纸缺失的问题仍在，重新安装可恢复。
