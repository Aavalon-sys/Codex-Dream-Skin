# Hazel · Codex Dream Skin v1.5.22

[中文](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.22/docs/releases/v1.5.22.md) · **English**

Fixes two hairline artifacts at the seam between the sidebar and the content area, and gives Windows its own layout; the macOS and Windows layouts are now independent.

## Fixes and improvements

- **Sidebar scrollbar (macOS)**: scrolled to the end, the conversation list's scrollbar no longer pokes past the sidebar's rounded bottom-right corner.
- **Resize guide line (macOS)**: hovering the drag area between the sidebar and the content shows the guide line only along the straight part of the seam, no longer through the gaps at the rounded corners.
- **Windows layout**: square edges for the sidebar and content panels; the brand moves to the middle of the window's menu bar and hides on narrow windows; the thread's top and bottom fades use the theme background; the ambient figure and hero artwork are re-aligned and re-scaled.
- **Platform separation**: the Windows adjustments above apply only on Windows; the macOS layout is unchanged.

## Upgrading and usage

- **macOS**: rerun the one-line installer from the README, or download the new DMG; the active theme is kept.
- **Windows**: download the new Setup.exe and install over the existing one. The installer is tested and built on GitHub Actions' Windows runners and has not yet been checked on a physical Windows machine; the chibi sticker still drops when switching to another saved theme from the tray and back to Hazel, and reinstalling restores it.
