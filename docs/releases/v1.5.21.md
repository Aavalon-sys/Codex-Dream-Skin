# 灰泽满 Hazel · Codex Dream Skin v1.5.21

**中文** · [English](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.21/docs/releases/v1.5.21-en.md)

灰泽满主题移到上游 Codex Dream Skin v1.5.21 之上，并适配 ChatGPT 与 Codex 合并界面后的 Codex 26.1013。这是本 fork 第一个基于上游 1.5 系列的版本，macOS 与 Windows 都提供安装包。

## 新增功能

- **默认主题为灰泽满**：macOS 与 Windows 全新安装后直接使用灰泽满主题；上游公开预设 Gothic Void Crusade 仍在已保存的主题里可选。已经在用其他主题的安装，升级后保持原主题。
- **ChatGPT 侧也有立绘**：ChatGPT 首页、聊天和工作页右侧显示半透明的灰泽满立绘，底部渐隐。
- **更新来源**：检查更新与下载链接指向本 fork 的 Releases。

## 修复与改进

- **Codex 首页**：修复空白占位卡片把输入框挤出窗口、建议列表文字消失；窗口较矮或出现额度横幅时，主卡片在 300px 到 240px 之间自动收缩。
- **语录**：固定在主卡片内、立绘左侧，没有主卡片的页面不再显示游离的语录。
- **品牌字**：「灰泽满 Hazel / 绿冻工作台」移到侧栏上方的标题栏，侧栏收起时自动隐藏，不与会话标题重叠。
- **侧栏与内容区接缝**：去掉面板贴合后多余的投影与描边；两个圆角之间的区域与标题栏同色；侧栏收起时上下圆角对齐。
- **macOS**：切到其他主题再切回灰泽满，Q 版贴纸不再丢失。

## 升级与使用

- **macOS**：可以用 README 中的一键安装命令，也可以下载 DMG。从 1.4.x 升级时会替换旧引擎，当前激活的主题保留。公开安装包没有 Apple 签名，DMG 首次打开需按[安装说明](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.21/docs/install-macos.md)放行；一键安装命令不需要这一步。
- **Windows**：安装包由 GitHub Actions 的 Windows 环境自动测试并打包，尚未在实体 Windows 设备上验收。已知问题：在托盘「已保存的主题」里切到其他主题再切回灰泽满，Q 版贴纸会缺失，主题其余部分不受影响；重新安装可恢复。
- **素材**：立绘与贴纸版权归原作者与角色相关方，不在 MIT 许可范围内，详见 [NOTICE](https://github.com/Aavalon-sys/Codex-Dream-Skin/blob/v1.5.21/macos/NOTICE.md)。
